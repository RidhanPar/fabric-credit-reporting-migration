# Measure dictionary

Generated by `scripts/build_semantic_model.py` from the semantic model. Each
measure's description is also stored in the model itself, so the definition
travels with the number into Power BI tooltips.

Do not edit this file by hand.

## Portfolio

### Portfolio balance (EUR)

Balance of active accounts in EUR at a month end, converted at that month's closing rate. A balance is a stock, so over a longer period this reports the latest month end in the period rather than a sum of month ends.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Portfolio balance (EUR) = LASTNONBLANKVALUE(dim_date[date_key], CALCULATE(SUM(fact_balance_snapshot[balance_eur]), fact_balance_snapshot[is_active] = TRUE()))
```

### Portfolio balance last month (EUR)  (hidden)

The portfolio balance one month earlier, used by the growth measure. Time intelligence like this only works because dim_date is marked as the model's date table.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Portfolio balance last month (EUR) = CALCULATE([Portfolio balance (EUR)], DATEADD(dim_date[date], -1, MONTH))
```

### Portfolio balance MoM %

Month on month growth of the portfolio balance.

Table: `fact_balance_snapshot`. Format: `0.0%`.

```dax
Portfolio balance MoM % = DIVIDE([Portfolio balance (EUR)] - [Portfolio balance last month (EUR)], [Portfolio balance last month (EUR)])
```

### Active accounts

Accounts with an active status at a month end. Semi additive, like the balance.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Active accounts = LASTNONBLANKVALUE(dim_date[date_key], CALCULATE(COUNTROWS(fact_balance_snapshot), fact_balance_snapshot[is_active] = TRUE()))
```

### Active customers

Distinct customers holding at least one active account at a month end. A customer with a loan and a card counts once.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Active customers = LASTNONBLANKVALUE(dim_date[date_key], CALCULATE(DISTINCTCOUNT(fact_balance_snapshot[customer_id]), fact_balance_snapshot[is_active] = TRUE()))
```

### Avg balance per customer (EUR)

Portfolio balance divided by distinct active customers. This is the definition agreed in the migration. The legacy pack divided by active accounts, which is a different number.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Avg balance per customer (EUR) = DIVIDE([Portfolio balance (EUR)], [Active customers])
```

## Migration

### Avg balance per account (EUR)

The legacy definition of average balance, kept so the old and new figures can be compared during the parallel run.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Avg balance per account (EUR) = DIVIDE([Portfolio balance (EUR)], [Active accounts])
```

### Approval rate (legacy definition)

The legacy definition: approved over everything received, including withdrawn and incomplete. Kept for the parallel run, and it reads about 5 points lower.

Table: `fact_application`. Format: `0.0%`.

```dax
Approval rate (legacy definition) = DIVIDE([Applications approved], [Applications received])
```

## Credit quality

### Balance 30+ DPD (EUR)

Balance of active accounts 30 or more days past due, at a month end.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Balance 30+ DPD (EUR) = LASTNONBLANKVALUE(dim_date[date_key], CALCULATE(SUM(fact_balance_snapshot[balance_eur]), fact_balance_snapshot[is_dpd30] = TRUE()))
```

### 30+ DPD rate

Balance 30 or more days past due as a share of the active portfolio balance. A balance weighted rate, not an account count rate, because it is the money at risk that matters for impairment.

Table: `fact_balance_snapshot`. Format: `0.00%`.

```dax
30+ DPD rate = DIVIDE([Balance 30+ DPD (EUR)], [Portfolio balance (EUR)])
```

### Balance 90+ DPD (EUR)

Balance of active accounts 90 or more days past due, at a month end. Accounts are written off at 180 days, so they leave this measure then.

Table: `fact_balance_snapshot`. Format: `#,0`.

```dax
Balance 90+ DPD (EUR) = LASTNONBLANKVALUE(dim_date[date_key], CALCULATE(SUM(fact_balance_snapshot[balance_eur]), fact_balance_snapshot[is_dpd90] = TRUE()))
```

### 90+ DPD rate

Balance 90 or more days past due as a share of the active portfolio balance.

Table: `fact_balance_snapshot`. Format: `0.00%`.

```dax
90+ DPD rate = DIVIDE([Balance 90+ DPD (EUR)], [Portfolio balance (EUR)])
```

### 30+ DPD rate last month  (hidden)

The 30+ rate one month earlier, used by the change measure. Hidden, because a report author should pick the change measure rather than build the subtraction again.

Table: `fact_balance_snapshot`. Format: `0.00%`.

```dax
30+ DPD rate last month = CALCULATE([30+ DPD rate], DATEADD(dim_date[date], -1, MONTH))
```

### 30+ DPD rate change

Change in the 30+ rate against the previous month, in percentage points.

Table: `fact_balance_snapshot`. Format: `+0.00%;-0.00%;0.00%`.

```dax
30+ DPD rate change = [30+ DPD rate] - [30+ DPD rate last month]
```

## Origination

### New accounts

Accounts disbursed in the period, counted in the month the money left the building.

Table: `fact_origination`. Format: `#,0`.

```dax
New accounts = COUNTROWS(fact_origination)
```

### New originations (EUR)

Amount disbursed in the period, in EUR. A flow, so it is converted at the monthly average rate rather than the month end rate.

Table: `fact_origination`. Format: `#,0`.

```dax
New originations (EUR) = SUM(fact_origination[amount_eur])
```

### Avg loan size (EUR)

Average amount disbursed per new account.

Table: `fact_origination`. Format: `#,0`.

```dax
Avg loan size (EUR) = DIVIDE([New originations (EUR)], [New accounts])
```

## Applications

### Applications received

Applications submitted in the period, whatever happened to them.

Table: `fact_application`. Format: `#,0`.

```dax
Applications received = COUNTROWS(fact_application)
```

### Applications decisioned

Applications that reached a credit decision: approved or declined. Withdrawn and incomplete applications are excluded.

Table: `fact_application`. Format: `#,0`.

```dax
Applications decisioned = CALCULATE(COUNTROWS(fact_application), fact_application[is_decisioned] = TRUE())
```

### Applications approved

Applications approved in the period, counted by the month the application was submitted, so approvals line up with the demand that produced them.

Table: `fact_application`. Format: `#,0`.

```dax
Applications approved = CALCULATE(COUNTROWS(fact_application), fact_application[is_approved] = TRUE())
```

### Approval rate

Approved as a share of decisioned applications. This is the definition agreed in the migration, because an application nobody decided says nothing about credit appetite.

Table: `fact_application`. Format: `0.0%`.

```dax
Approval rate = DIVIDE([Applications approved], [Applications decisioned])
```

## Collections

### Repayments (EUR)

Payments received in the period, in EUR at the monthly average rate.

Table: `fact_repayment`. Format: `#,0`.

```dax
Repayments (EUR) = SUM(fact_repayment[amount_eur])
```

## Trust

### Quality checks run

Data quality checks recorded for the runs in context.

Table: `dq_results`. Format: `#,0`.

```dax
Quality checks run = COUNTROWS(dq_results)
```

### Quality checks failed

Checks that failed. An ERROR here means gold did not publish.

Table: `dq_results`. Format: `#,0`.

```dax
Quality checks failed = CALCULATE(COUNTROWS(dq_results), dq_results[passed] = FALSE())
```

### Legacy error effect (EUR)

How much of the difference between the legacy pack and the new model is explained by faults in the legacy formulas, on the portfolio balance. Negative means the legacy pack was too high.

Table: `recon_attribution`. Format: `#,0`.

```dax
Legacy error effect (EUR) = CALCULATE(SUM(recon_attribution[amount]), recon_attribution[classification] = "LEGACY_ERROR", recon_attribution[kpi] = "portfolio_balance_eur")
```

### Unexplained differences

Published figures whose difference has no named cause. This must be zero, or the migration is not finished.

Table: `recon_attribution`. Format: `#,0`.

```dax
Unexplained differences = CALCULATE(COUNTROWS(recon_attribution), recon_attribution[classification] = "UNEXPLAINED")
```
